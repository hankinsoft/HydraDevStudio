# Hydra Dev Studio: issues and feature requests

This is the public issue tracker for [Hydra Dev Studio](https://hydradevstudio.com/),
the native macOS workspace for databases, file servers, cloud storage, SSH and Git.
The app's source is not here; this repository holds reports and requests only.

- **Found a bug?** [Report it](https://github.com/hankinsoft/HydraDevStudio/issues/new?template=bug_report.yml).
- **Want something?** [Request a feature](https://github.com/hankinsoft/HydraDevStudio/issues/new?template=feature_request.yml).
- **Anything private** (licences, orders, server details you would rather not post):
  email [kyle@hankinsoft.com](mailto:kyle@hankinsoft.com?subject=Hydra%20Dev%20Studio).
- **Security issues:** email the same address with "security" in the subject.
  Please do not open a public issue.

From inside the app, **Help › Report an Issue…** opens the form with your
version and macOS version already filled in.

**Issues here are public.** Never paste passwords, keys, tokens, connection
strings or anything that identifies your servers. Nothing about diagnosing a
problem needs them.
